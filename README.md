# 🚀 Alexa's Interactive Portfolio

A modern, responsive personal portfolio website built to showcase my computer science projects, technical skills, and achievements. Designed with a dark "developer" aesthetic featuring glassmorphism UI elements and smooth scroll animations.

🔗 View Live Demo (Note: Update this link to your actual GitHub Pages URL)

# ✨ Features

**Modern UI/UX:** Dark mode theme with neon accents and glassmorphism card designs.

**Bento Grid Layout:** Clean, scannable layout that highlights key information instantly.

**Fully Responsive:** Fluid design that adapts perfectly to desktop, tablet, and mobile screens.

**Scroll Animations:** Custom intersection observers trigger fade-in animations as the user scrolls down the page.

**Ambient Background:** CSS-driven animated gradient blobs and grain overlays for a premium feel.

# 🛠️ Technologies Used

**HTML5** - Semantic markup and structure

**Tailwind CSS (via CDN)** - Utility-first CSS framework for rapid styling and responsiveness

**Vanilla JavaScript** - For Intersection Observer scroll animations

**FontAwesome** - For scalable vector icons

**Google Fonts** - Inter for readability and Fira Code for monospace tech accents
